# Object-Oriented Programming & Algorithm Implementations

This repository contains a curated collection of Object-Oriented Design (OOD) projects, data structure modules, and algorithm implementations in C++.
Built with a focus on modularity, inheritance, clean architecture, and practical software design.

---

## Major Projects

### Fantastic Beasts and Paths To Find
A grid-based pathfinding engine that models spatial environments and calculates optimal trajectories across complex maps.
* **Features**: Dijkstra’s Algorithm, A* Search, BFS/DFS traversal, custom cost heuristics.

### Geosolitaire
A spatial board game simulation implementing coordinate tracking, state machines, and move history management.
* **Features**: Encapsulated board state, coordinate math, state machine pattern, undo/redo execution stack.

### Library Management System
A complete record management application handling user roles, book catalogs, and transactional workflows.
* **Features**: Role-based access control (Admin/Member), CRUD operations, file stream persistence.

### Battle Simulation
A dynamic C++ turn-based combat simulator modeling interactions between diverse entity classes with distinct attributes and special abilities.
* **Features**: Abstract base classes, virtual functions, dynamic method dispatch, factory design pattern.

---

## Minor Projects & Modules

### Galactic Chessmaster
A custom chess mechanics system evaluating piece movements, attack paths, and board states on spatial grids.
* **Focus**: Matrix operations, class inheritance for pieces, movement vector validation.

### Graph Operations
A foundational C++ graph library implementing core data structures and fundamental algorithms from scratch.
* **Focus**: Topological sort, cycle detection, connected components, Kruskal’s and Prim’s Minimum Spanning Trees (MST).

### Harry Potter and Enchanted Events
An event-processing module designed to schedule and execute simulated events based on dynamic timestamps and priorities.
* **Focus**: Priority queues, min/max heaps, event loop architecture, custom struct comparators.

### Ramanujan and Polynomials
A mathematical computation engine capable of representing, evaluating, and operating on arbitrary-degree polynomials.
* **Focus**: C++ operator overloading (`+`, `-`, `*`), dynamic arrays, Horner's method for polynomial evaluation.

## Technologies Used

* **Language**: C++ (C++17)
* **Libraries**: STL (`vector`, `unordered_map`, `unordered_set`, `queue`, `priority_queue`)
* **Concepts**: Object-Oriented Programming (Polymorphism, Encapsulation, Inheritance), Graph Theory, Data Structures, State Machines
